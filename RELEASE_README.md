# rsync for Git Bash

## Description
This package contains a standalone build of `rsync` compiled specifically for use within Git for Windows (Git Bash). It is designed to be compatible with the runtime environment of its target Git for Windows version to prevent Application Binary Interface (ABI) mismatch errors.

## About Rsync
`rsync` is an open-source utility that provides fast incremental file transfer.
For more information, documentation, and the original source code, please visit the official rsync project page: [https://rsync.samba.org/](https://rsync.samba.org/)
